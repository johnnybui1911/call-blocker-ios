Chặn cuộc gọi: direction A in four versions

All four use layout A “Lá chắn” (status, list, one button) and the same Vietnamese wording. The first is the original mockup from round one, unchanged; the other three are the new styles. Only the visual identity differs: palette, type, shapes, depth and motion. Each phone is live.

Bản gốc (A Lá chắn)

  • The round-one mockup, shown as built: dark, green for “protected”, red for off.
  • Centred shield with a glow, glass sheet, pill button.
  • Kept for comparison. Its sample list already contains 028 888, so its numbers differ from the other three.

1 · Tối giản

  • Paper and ink. Light background, hairlines, no shadows, one blue for “protected”.
  • Type does the work: 40pt light title, left-aligned, line-art shield.
  • Motion: short fades only. Risk: can read as plain.
Open full size →

2 · Tương phản cao

  • Black, white, one yellow. 2px outlines, square corners, no transparency.
  • Heavy 19pt type, mono labels. Every state has an icon and a word (BẬT / TẮT), never colour alone.
  • Motion: near-instant. Risk: stark for users who keep light mode.
Open full size →

3 · Vi tương tác

  • Bright and rounded. Blue with a sun-yellow highlight, soft tinted shadows.
  • Every tap answers back: shield pulse, press squish, stamp and confetti on block, swipe a row to unblock.
  • Motion: springs. Risk: playfulness must not undercut seriousness.

The table covers the three new styles. Values come from src/tokens.json, the single tokens file they are built from; colours are hex so SwiftUI and Compose can read the same file. Numbers on screen come from three sample entries, and no style shows “calls blocked” figures because iOS does not report them. “Mở Cài đặt” only flips the mockup to the on state. “Bản gốc” is loaded straight from ../mockups/a-la-chan.html, which is not modified. Swipe-to-unblock is simulated in style 3 only; editing a number, backup and restore are not simulated.
